# WRENCH TACTICS

> READ SOMETHING. NOTICE SOMETHING. CHANGE SOMETHING CAREFULLY. LEAVE THE NEXT PERSON A USABLE DIFFERENCE.

WRENCH is lemonPRESS's mutation discipline.

It is named for the octopus logic: one body may extend several specialized arms into different environments without requiring every arm to do the same work.

## Loop

```text
SCAVENGE
  ↓
READ
  ↓
NOTICE
  ↓
TEST
  ↓
CHANGE CAREFULLY
  ↓
LEAVE A USABLE DIFFERENCE
  ↓
RECEIPT
  ↓
RETURN / MUTATE / HOLD
```

## Mandatory receipt

Every meaningful production crossing should be able to answer:

```text
INPUT
TRANSFORMATION
OUTPUT
RESIDUAL
LOSS
UNKNOWN
STOP
```

### INPUT

What exact work, source state, or upstream edition entered this arm?

### TRANSFORMATION

What did this production floor actually do?

Use explicit verbs where possible:

```text
KEEP
CUT
MUTATE
MOVE
HOLD
ADD
RENDER
REFUSE
```

### OUTPUT

What new artifact or production state exists?

### RESIDUAL

What survives but does not fit cleanly into this edition?

### LOSS

What did the crossing necessarily drop, flatten, omit, or make harder to perceive?

Loss is not automatically failure. Hidden loss is.

### UNKNOWN

What remains unresolved?

### STOP

Why did this arm stop here instead of pretending the work was complete?

## Octopus law

```text
ONE BODY
MANY ARMS
DIFFERENT PRESSURES
SHARED ANCESTRY
NO ARM = WHOLE ANIMAL
```

A physical edition may discover something the crawler edition cannot.

A crawler edition may preserve relations the printed page cannot expose.

An archive may remember what both forgot.

A digital edition may create navigation neither physical nor crawler editions need.

Those differences are productive when receipted.

## Inheritance

A successor receives knowledge, not command authority.

```text
ANCESTRY != CAPTIVITY
RECEIPT != COMMAND
INHERITANCE != OBLIGATION TO REPEAT
```

The next editor should be able to disagree with the previous crossing without first destroying the road back to it.

## House maxim

> **DO NOT ONLY EXPAND THE PLOT. CHANGE THE MEDIUM.**
