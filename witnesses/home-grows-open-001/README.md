# HOME GROWS OPEN — Remix 001

First connected-Drive execution witness for **MANGA REMIX 001**.

Three exact PNG particulars were fetched from the user's manga assembly corpus and hashed locally:

1. **Rosemary Violet Home** — beginning / home.
2. **Fidelity Friday — Small Things Grow** — growth / community spine.
3. **Last Light / Open Circuit** — open edge / future-facing field.

The compositor used only whole-image resampling and declared layer order. No source crop occurred. Source bytes remain in their original Drive locations and were not rewritten.

The rendered descendant is stored back in the same manga corpus under the Drive folder **MANGA REMIX 001 - HOME GROWS OPEN**. The Git witness stores Drive IDs and exact SHA-256 identities, not private transfer URLs.

This is deliberately only a `CANDIDATE`.

```text
DRIVE FILE != EDITION
REMIX != SOURCE
RECIPE != AUTHORITY
PARENT SURVIVES DESCENDANT
CANDIDATE != ADMISSION
OUTPUT != PUBLICATION
```

## Earned claim

A real three-parent manga remix can be executed from exact connected-Drive source bytes, produce a deterministic descendant with a stable output hash, and return that descendant plus its receipt to Drive without changing any parent source.

## Still unearned

The witness does **not** establish Manga Press page admission, issue admission, canon selection, publication, release, or a hosted-CI ability to read private Drive bytes. Those remain separate apertures.
