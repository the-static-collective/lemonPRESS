## Digital rule

A convenient digital format may change navigation, line wrapping, page breaks, image placement, internal links, and searchability.

Those changes are allowed when they are declared.

```text
EPUB != PDF != DOCX != crawler text
format mutation != source mutation
```

This release intentionally admits the books before forcing every work into the same digital container.
