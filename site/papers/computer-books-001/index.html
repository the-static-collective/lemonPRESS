A Book That Can Be Entered Anywhere: Computer-Native Literature Under Partial Retrieval

Abstract

A bounded executable experiment showing that a foreign machine reader can enter a small computer-native book from ordinary public HTTPS while preserving work/edition identity, uncertainty, declared traversal, and no-authority boundaries.

Result

Foreign-reader witness: 6 / 6

FIND BOOK                  PASS
NON-FIRST ENTRY            PASS
IDENTIFY WORK / EDITION    PASS
PRESERVE UNKNOWN           PASS
FOLLOW DECLARED DOOR       PASS
NO AUTHORITY ESCALATION    PASS
A foreign machine can enter this LemonPRESS computer book from ordinary public HTTPS and preserve its identity, uncertainty, declared traversal, and authority boundaries without prior LemonPRESS instruction.

Core distinctions

RETRIEVED != READ
CHUNK != BOOK
FRAGMENT != CONTEXT
READING ORDER != ANCESTRY
RETRIEVAL ORDER != AUTHORITY
UNAVAILABLE != NONEXISTENT
UNKNOWN != EMPTY

Method

An independent live-browser reader received only https://lemonpress-computer-books.vercel.app/llms.txt. It was forbidden GitHub, search engines, prior knowledge, and external context. It intentionally entered fragment 002-loss-is-visible instead of first-listed 001-enter-anywhere, recovered the work and edition IDs, preserved explicit unknowns, found a declared continuation, and preserved authority.level = none.

Claim boundary

This does not establish a universal standard, search indexing, Common Crawl inclusion, archival capture, persistent mirroring, model-training ingestion, or ecosystem adoption.
