# RENJI RELAY 001 — The Book That Survived the Door

Executable edge specimen for **TRANSFORM != SEVER**.

Five Google Drive PNGs are named only by stable external identity + observed SHA-256. They are not copied into this repository and no descendant may silently replace them.

## Route

```
source particulars
→ translate.through(ja → en)
→ declared remix sequence
→ declared style stack
→ LemonPRESS issue
→ reLATTE crossing
→ foreign local renderer with no LemonPRESS dependency
→ owner-local disposition + receipt
```

The far-side renderer is intentionally allowed to be incapable of reproducing the source aesthetic. Pixel similarity is not provenance.

## Pass/fail center

* pixel-identical output + broken ancestry = **FAIL**
* radically different output + complete declared ancestry = **PASS**
* local refusal of a valid crossing = **VALID REFUSAL**
* derived artifact claiming to be an original = **FAIL**

## Boundary

This specimen owns no reLATTE core semantics. It consumes the crossing/receiver boundary and preserves reLATTE's existing `ANCESTRY != AUTHORITY` / `RENDERING != AUTHORITY` laws.

Run:

```bash
python3 works/renji-relay-001/verify.py
```

The verifier is intentionally stdlib-only so a cold machine does not need LemonPRESS to audit the specimen declaration.
