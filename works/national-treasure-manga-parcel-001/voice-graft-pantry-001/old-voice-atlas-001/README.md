# OLD VOICE ATLAS 001

A link-first map of historical public-domain sound for Manga Cross.

The policy is deliberately **link broadly, house selectively**:

ARCHIVE FIELD -> USE CASE -> TARGETED DIG -> ITEM RIGHTS CHECK -> CUSTODY -> HASH / ORGANIZE ONLY WHEN NEEDED

The atlas currently points at UCSB / DAHR, Library of Congress National Jukebox + Citizen DJ, Wikimedia Commons historical-audio seams, and the Internet Archive Great 78 field.

## Freshest Old House Set 001

Ten historical voice-bearing recordings are already in durable connected-media custody:

- four from **1925**, the newest U.S. sound-recording year newly public domain in 2026
- six from **1888–1900**, representing the deep edge of recorded human voice

The 1925 set includes **A Curtain Lecture**, a genuine comic dialogue recorded August 31, 1925.

The deep set includes Tennyson, an attributed Whitman cylinder, Gladstone, Franz Joseph I, and two Edison Talking Doll recitations.

No connected-media SHA-256 is invented. Exact hashes wait for local materialization.

## Important rights seam

A historical recording can be public domain while a library's newly produced digital transfer carries separate terms.

PUBLIC DOMAIN RECORDING != FREE ARCHIVE TRANSFER
RECORDING RIGHTS != COMPOSITION RIGHTS
LINK != LICENSE
