## Laws

```text
SOURCE != ORGAN
ORGAN != CHARACTER
DONOR != AUTHORITY
LICENSE != PROVENANCE
GRAFT != IMPERSONATION
TRANSFORMATION != ERASURE
HASH BEFORE MIX
CANDIDATE != ADMITTED
```

Git stores recipes, hashes, and provenance rather than pretending uncommitted media already has durable public custody.
