## Exclusion rule

The scrape encountered many useful sounds sitting inside CC0 collections whose **individual source licenses were CC-BY, CC-BY-SA, GPL, or otherwise mixed**. Those were not silently promoted.

```text
COLLECTION MEMBERSHIP != LICENSE
SEARCH HIT != DONOR
DIRECT BINARY SUCCESS + EXPLICIT CC0 -> HARVEST CANDIDATE
```
