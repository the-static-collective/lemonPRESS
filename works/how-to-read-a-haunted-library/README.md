## What this edition is testing

This is a book whose form attempts to practice its own claim.

A crawler may encounter Chapter 8 before Chapter 1. Every major section therefore carries a small local receipt identifying the work and warning that the retrieved fragment is not the whole book.

The book teaches readers to preserve distinctions across summary, retrieval, transformation, inference, branching, and partial evidence.

## Core non-collapse set

```text
PARTICULAR != SUMMARY
SIMILARITY != IDENTITY
SOURCE != CLAIM
RETRIEVAL != COMPLETE READING
DOOR != CROSSING
DELTA != EXPLANATION
UNKNOWN != FALSE
```
