# nunuMATH Playground 001

A deliberately small executable descendant of **LP-NNM-101-001 — nunuMATH: Foundations of Admissive and Relational Mathematics**.

This is not the source book and does not supersede it.

```text
BOOK != INSTRUMENT
SOURCE != PROJECTION
ENDPOINT != PATH != TRACE
```

## What this slice makes executable

- strict first-course FIR worlds: `F ∩ I = ∅`;
- stable addressability for all F/I judgments and relation participants;
- typed relation instances;
- the fine constitutional delta `δ*(m) = (F+, F−, I+, I−, R+, R−)`;
- the coarse six-count signature;
- derived mathals between validated FIR worlds;
- receipts with warrant, trace, and declared question classes;
- three concrete receipt lenses: endpoint, delta, and history;
- seven specimens: apple gift, apple loss, debt, missing information, contradictory witnesses, remix, and room entry.

## Run

Open `index.html` in a modern browser. No build step and no network dependency are required.

For the executable checks:

```bash
npm test
```

## Front-door experiment

Both of these compress numerically to `3 − 1 = 2`:

1. give `apple:c` to a neighbor;
2. lose `apple:c` with destination unknown.

The playground intentionally refuses to identify them merely because the scalar endpoint agrees. The gift creates a recipient possession relation and a `gave` relation; the loss does not. Their receipts also retain different traces.

## Constitutional restraint

This slice implements only claims needed for the finite specimens. It does **not** claim to provide:

- a universal foundation for mathematics;
- proof of globally minimal receipts;
- multi-authority or paraconsistent FIR worlds;
- a theorem prover;
- a general-purpose ontology;
- a proof that every everyday action should be represented in FIR.

The book remains authoritative for the mathematical exposition. This playground is one digital production crossing that makes a small subset touchable.
