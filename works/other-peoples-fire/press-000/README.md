# Other People's Fire · PRESS 000 — The First Spark

**Status:** experimental linked-listening prototype / **HOLD** · 2026-10-26. This is **not** a lemonPRESS house admission, artist-approved release, redistributed audio, authorized compilation, physical pressing, or field-tested playback claim.

## See the specimen

Open [index.html](index.html) locally in a browser. It is a standalone responsive HTML page, with no build step, tracker, remote font or bundled audio. Tap **Load Suno player** to request the Suno-hosted player explicitly; **Open the original song on Suno** is the fallback. The vinyl animation is a visual control only and cannot reflect the media player's playback state.

## Why this belongs on an experiment branch

lemonPRESS's `main` owns admission and catalog state. Digital editions are authored under `press/digital`. This exploratory branch is **based on `press/digital`** and should remain a draft, not a silent admission of a musical work.

The sleeve demonstrates a recoverable route from a source reference to a human-facing proposed edition. It deliberately does **not** imply that SIA, GRAFT and JAR;VIS have been stitched together as a live automatic pipeline.
