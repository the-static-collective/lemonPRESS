# Other People's Fire — PRESS 001 / held vinyl preflight

This owner-native executable extension to PRESS 000 turns a source-linked A1 and a witness-only Band Runtime review into deterministic **vinyl-shaped draft proof artifacts**. It never manufactures vinyl, copies media, claims a real room encounter, or admits the work to lemonPRESS. The first 12-song / 11-artist compilation remains a curatorial target, not a confirmed licensed track listing. Artist copies, at-cost fulfillment, selected vendor and actual prices remain explicit review gates.

Run from this branch:

`node scripts/vinyl-preflight.mjs build --edition works/other-peoples-fire/press-000/edition.json --room test/fixtures/synthetic-room-review.json --out /tmp/press-001 --authorize LOCAL_DRAFT_ONLY`

`node scripts/vinyl-preflight.mjs verify --edition works/other-peoples-fire/press-000/edition.json --room test/fixtures/synthetic-room-review.json --out /tmp/press-001`

The visual sleeve/center label is **NOT FOR MANUFACTURE**. Missing master, timing, consent, final A/B sequencing, manufacturing quote, jacket proof, artist copy allotments, accounting, house admission, physical-order permission remain HOLD. No external vendor API or payments are contacted. A real record requires independently approved audio, rights and manufacturer-specific specifications.
