# CRAWLER PRESS

This branch publishes for readers who may never turn a page.

A crawler, retrieval system, search engine, model, archive, or future machine may encounter a work as one fragment, one cached page, one embedding, one quotation, or one damaged copy.

That is a legitimate arrival.

It is not the whole book.

## Scope

- clean Markdown
- plain text
- semantic HTML
- fragment-addressable editions
- manifests
- relation maps
- JSON-LD and other machine-readable metadata
- sitemap / feed / crawler discovery surfaces
- partial-retrieval experiments

## Laws

> **RETRIEVED != READ**

> **CHUNK != BOOK**

> **FRAGMENT != CONTEXT**

> **DISCOVERY != ENDORSEMENT**

> **A SEVERED LIMB SHOULD STILL KNOW WHICH BODY IT CAME FROM.**

Write for the possibility that page 93 is encountered first.
