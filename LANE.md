# DIGITAL PRESS

This branch produces human-facing digital lemonPRESS editions.

## Scope

- web editions
- EPUB
- accessible PDF
- downloadable text editions
- navigation and reading interfaces
- ordinary metadata and distribution packages

## Law

Digital navigation may change how a reader moves without changing source ancestry.

> **NAVIGATION != NARRATIVE ORIGIN**

> **FORMAT CONVERSION != NEW AUTHORSHIP**

> **LATEST != AUTHORIZED**

Each published digital object should remain traceable to an admitted work and release.
